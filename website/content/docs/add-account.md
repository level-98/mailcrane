Account setup is not available in a public app build yet. The planned flow covers supported providers and manual IMAP/SMTP settings.

When the app is released, this guide will explain how to choose a provider, sign in, and verify your connection. Until then:

- Review the [provider status pages](@/docs/providers/_index.md).
- Never send your password, app password, OAuth code, or private mail to the project or in a public issue.
- If you need help with the roadmap, use [GitHub Discussions](https://github.com/level-98/mailcrane/discussions) without sharing account details.
