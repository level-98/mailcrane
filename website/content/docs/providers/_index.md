Mailcrane works with any provider that offers IMAP and SMTP, or JMAP; see [Add an account](@/docs/add-account.md). These guides add provider-specific notes as they’re written. A provider counts as verified only once it appears in the [provider test matrix](https://github.com/mailcrane/mailcrane/issues/48).

Do not send account passwords or private mail to anyone helping with provider testing.
