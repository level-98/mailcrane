Manual IMAP and SMTP setup is planned so that providers without a dedicated guide can still be supported. Mailcrane is not available to download until the beta planned for December 2026, so hostnames, ports, and sign-in instructions are not published here.

Provider-specific settings will be documented only after they have been tested. See the [provider test matrix](https://github.com/level-98/mailcrane/issues/48) for coverage status.
