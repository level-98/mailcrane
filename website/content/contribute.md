Mailcrane is built in the open by contributors and AI agents. The app is early-stage, so the roadmap includes both implementation work and design, documentation, and provider testing.

- Read the [contributor guide](https://github.com/mailcrane/mailcrane/blob/main/CONTRIBUTING.md).
- Browse [open issues](https://github.com/mailcrane/mailcrane/issues) and [good first issues](https://github.com/mailcrane/mailcrane/labels/good%20first%20issue).
- Join [GitHub Discussions](https://github.com/mailcrane/mailcrane/discussions).
- See the [provider test matrix issue](https://github.com/mailcrane/mailcrane/issues/48) if you can test with a real provider.

Translations are planned after the Weblate setup task in the roadmap. Please do not include real email addresses, credentials, or message content in issues or screenshots.
