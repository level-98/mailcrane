Mailcrane is in early development. These are the goals guiding the project, not a claim that every feature is already available.

## Private by default

No ads, analytics, or Mailcrane-operated mail servers. Remote images are planned to stay blocked until you choose to load them, and tracker stripping is part of the roadmap.

## Your provider, your choice

The project is being built around open mail standards: IMAP and SMTP, with JMAP and guided sign-in planned for supported providers. See the [provider guides](@/docs/providers/_index.md) for current status.

## Native and offline-minded

Mailcrane is planned for Android and iOS with native interfaces and a shared Rust engine. Local storage and offline access are core design goals.

## Thoughtful everyday tools

The roadmap includes a unified inbox, search, attachments, snooze, scheduled send, and more. The [live roadmap](@/_index.md) follows the GitHub issues.

## Open source

The project is developed in public. Read the [contributor guide](https://github.com/level-98/mailcrane/blob/main/CONTRIBUTING.md) or [find a task](https://github.com/level-98/mailcrane/issues).
