> **Draft:** Mailcrane is not released yet. This page describes the website and current project intentions; it is not the final app privacy policy. The owner must review the app's actual network behaviour and approve the release policy before publication.

## This website

This is a static website. It does not set cookies, run analytics or advertising scripts, or load fonts, images, or scripts from third-party services. The roadmap snapshot is generated during website builds and served as a local file.

The site is hosted with GitHub Pages. When your browser requests a page, GitHub may process technical request data under its own policies. Following an external link to GitHub or a future app store also takes you to that service.

## The app

There is no Mailcrane app available to download yet. The project intends to avoid ads and analytics and to connect mail directly to the provider you add. Sign-in may involve your provider's authentication service; loading remote message images would contact the image host only after you choose to load them. These details will be checked against the released app before this page is finalized.

The final policy will describe every network destination, permission, and exception in plain language. See [issue #75](https://github.com/level-98/mailcrane/issues/75) for the owner review and release checklist.

## Contact

For general policy questions, contact the maintainers through [GitHub Discussions](https://github.com/level-98/mailcrane/discussions). Do not post private account information or security reports in public discussions.
