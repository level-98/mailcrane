You can make rules that sort new mail on this device: when a message is from someone, to or cc someone, has a subject, has an attachment or comes from a mailing list, Mailcrane can move it, archive it, delete it, flag it or mark it read. Rules run in the order you set, can stop later rules, can be run on the inbox you already have, and can be created from a message ("Create rule from this message"). Each message is handled once, even after a resync.
