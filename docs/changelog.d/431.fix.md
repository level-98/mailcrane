Snoozing a message again while it's being woken no longer leaves a copy in the Inbox as well as in Snoozed. The new snooze now waits for the wake to finish, and the message ends up snoozed once, until the newer time. If the wake hadn't moved the message yet, it's snoozed again straight away, without first showing up unread in the Inbox. Undoing that snooze, or snoozing it again from the Snoozed folder, now works too.
