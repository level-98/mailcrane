Sent messages now appear in your Sent folder on every device: after sending, Mailcrane uploads an exact copy, except for providers that do this themselves (Gmail, Outlook.com and Microsoft 365), where it would make duplicates. A new account setting, "Save sent messages to the Sent folder" (Automatic, On, Off), overrides this. If there is no Sent folder, one is created. A copy that cannot be saved shows in the Outbox to retry, and the message is never sent again because of it.
