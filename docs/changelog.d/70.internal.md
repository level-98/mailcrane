Release workflow for Android: a `v*` tag (or a manual run) checks the tag against `versionName` and `versionCode` with the new `cargo xtask release-check`, runs `cargo xtask ci`, builds the release APK and AAB, signs them in a separate job of the `release` environment with a keystore from its secrets, and attaches them with `SHA256SUMS` to a draft GitHub Release. Without the secrets it leaves the files unsigned and says so. docs/releasing.md explains the key, the secrets and the release steps.
