Debug builds have a "Load test mail" row in Settings. It adds a local-only Fixtures account (`fixtures@example.org`) with every message from `tests/fixtures`, for checking screens on an emulator without a real mailbox. The account never syncs or connects, and loading again replaces its messages. Release builds contain neither the row nor the loader: `cargo xtask ci` checks this, and the build refuses to package a release APK with a debug-built core.
