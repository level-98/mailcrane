Drafts: whatever you type is saved on the device two seconds after you stop typing, and when you close the compose screen ("Draft saved"). Drafts are uploaded to your Drafts folder when online, so other devices see them, and a message in the Drafts folder opens for editing. Sending deletes the draft; a new Discard button deletes it on purpose. "Drafts on this device" in the folder drawer lists every draft, including ones not uploaded yet. If another device changed a draft at the same time, both versions are kept.
