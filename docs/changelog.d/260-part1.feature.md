Tapping a link in a message now shows where it really goes (the destination site in large text) before it opens, and warns when the link text names a different site, the address is an IP number or has "user@" in front, mixes alphabets, or is not secure. Warnings are hints: you can always open the link. A new setting, "Confirm links before opening", is on by default; links with a warning are always confirmed.
