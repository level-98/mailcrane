You can snooze a message: it leaves the folder and comes back unread at the time you pick (later today, tomorrow, this weekend, next week, or a date and time you choose), with a notification. Snoozed messages wait in a "Snoozed" folder on your server, and other Mailcrane installs learn the wake time from it when the server allows; if it doesn't, the message view says only this device will bring it back.
