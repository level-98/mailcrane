# 0000: App Name

* **Status:** accepted
* **Date:** 2026-11-24

## Context
We need a distinct, official application name to establish project identity, unify product branding, and guide design and codebase naming conventions across the project. 

## Decision
The application name will be **Mailcrane**.

## Rationale
* **Uniqueness:** The name is distinct and not currently in use by active competing projects or developers.
* **Asset Readiness:** Brand assets, visual concepts, and design work have already been produced around this identity.
* **Clarity:** It provides a clear, memorable project identifier for repository references, documentation, and UI text.

## Consequences
* The project branding and repository references will be locked to **Mailcrane**.
* UI components, logos, and visual assets associated with Mailcrane can be integrated into the main branch.
* Any future name changes would require refactoring domain names, repo references, design assets, and codebase constants.
